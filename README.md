## 📊 Objetivos del análisis

- Identificar los géneros de videojuegos más comunes
- Determinar qué plataformas publicaron más títulos
- Analizar las ventas globales por género
- Observar la evolución de lanzamientos a lo largo del tiempo
- Explorar la relación entre puntuaciones y ventas

---

## 🛠️ Tecnologías utilizadas

- Python 3.x
- Jupyter Notebook
- Pandas
- Matplotlib
- Seaborn

---
🗃️ Fuente de datos
El conjunto de datos original proviene de Kaggle: Video Game Sales, y fue adaptado para este análisis.
